全局 Hermes Agent 模型

这里配置的是所有用户 Hermes Agent 启动时写入 ${HERMES_HOME}/config.yaml 的原生字段。保存后会进入全局策略；新建或重建的用户容器会同步，已运行用户需要重新 Spawn。

实际保存位置：model_policy.local_model。用户容器启动时会转换为 model.provider/default/base_url/api_key。

用户可选模型

推荐选择“混合路由”：用户可以在 safe、quality、fast 档位之间选择；敏感数据、数据库、终端、代码执行、私有 MCP 工具会强制走 safe 档位，在线档位只用于非隐私任务。
